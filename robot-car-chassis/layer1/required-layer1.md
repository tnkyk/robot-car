# ロボットカー装甲 要件定義書 v4

## 概要
ロボットカーは３段構成で各層にパーツを配置していく

## 制約
- 3Dプリンターの最大造形体積(W×D×H)：180×180×180 mm³
- 上記制約により、1層目の板はX軸中心で2分割して3Dプリント後に結合する

## 構成

### 1層目

#### 形状
- 四角形

#### サイズ
- 240×175×6 mm³
- 座標(0,0,0)を中心として上記サイズの板を設置
- 以下要件において共通的に以下の定義で表記する（なお、x,yは板を条件に従って設置した時の頂点の絶対値を示す）
  - x = 120mm, y = 87.5mm
  - 頂点A:(x, y, 0) = (120, 87.5, 0)
  - 頂点B:(x, -y, 0) = (120, -87.5, 0)
  - 頂点C:(-x, y, 0) = (-120, 87.5, 0)
  - 頂点D:(-x, -y, 0) = (-120, -87.5, 0)

#### 分割
- 3Dプリンターの制約により、X軸の中心(X=0)で2分割する
- 右側板(Layer1_Right): X: 0〜120mm, サイズ: 120×175×6mm
- 左側板(Layer1_Left): X: -120〜0mm, サイズ: 120×175×6mm

#### 板結合機構

##### くぼみ（凹）
- 目的: 分割した2枚の板を結合するための溝
- 配置: 各板の接合面側（X=0付近）に3箇所ずつ
- くぼみサイズ（各板）: 10×30×4mm
- 両板接合時の合計サイズ: 20×30×4mm
- Z位置: 上面から4mm掘り込み（Z: 2〜6mm）

| 板 | くぼみX範囲 | くぼみY中心位置 |
|----|------------|-----------------|
| 右側板 | 0〜10mm | 50, 0, -50mm |
| 左側板 | -10〜0mm | 50, 0, -50mm |

##### はめ込み部品（凸）- Connectors
- 目的: くぼみにはめ込んで2枚の板を固定する
- 個数: 3個
- サイズ: 19.8×29.8×3.8mm
- クリアランス: 0.2mm（3Dプリントの公差を考慮）

#### 穴

##### モーター固定用穴 - A
- M3インサートナット用（直径4.5mm）
  - A-1: 円の中点の座標：(x-50mm, y-21mm, 0) = (70, 66.5, 0)
  - A-2: 円の中点の座標：(x-58.5mm, y-21mm, 0) = (61.5, 66.5, 0)

##### モーター固定用穴 - B
- M3インサートナット用（直径4.5mm）
  - B-1: 円の中点の座標：(x-50mm, -y+21mm, 0) = (70, -66.5, 0)
  - B-2: 円の中点の座標：(x-58.5mm, -y+21mm, 0) = (61.5, -66.5, 0)

##### モーター固定用穴 - C
- M3インサートナット用（直径4.5mm）
  - C-1: 円の中点の座標：(-x+50mm, y-21mm, 0) = (-70, 66.5, 0)
  - C-2: 円の中点の座標：(-x+58.5mm, y-21mm, 0) = (-61.5, 66.5, 0)

##### モーター固定用穴 - D

  - D-1: 円の中点の座標：(-x+50mm, -y+21mm, 0) = (-70, -66.5, 0)
  - D-2: 円の中点の座標：(-x+58.5mm, -y+21mm, 0) = (-61.5, -66.5, 0)

## 3Dプリント情報

### 出力パーツ一覧

| パーツ名 | サイズ | 個数 | プリンター制限内 |
|----------|--------|------|------------------|
| Layer1_Right | 120×175×6mm | 1個 | ✓ |
| Layer1_Left | 120×175×6mm | 1個 | ✓ |
| Connector | 19.8×29.8×3.8mm | 3個 | ✓ |

### 組み立て手順
1. Layer1_RightとLayer1_Leftを3Dプリントする
2. Connectorを3個3Dプリントする
3. 左右の板を接合面（X=0）で合わせる
4. 3つのコネクタを上面のくぼみにはめ込む
5. 必要に応じて接着剤で固定する
