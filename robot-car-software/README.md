# アシスタントロボットカー

Raspberry Pi 4を使用したアシスタントロボットカーのソフトウェア実装です。

## 概要

特定の登録ユーザーを追跡し、音声コマンド（"Hey, Tom"）に応答してタスクを実行するロボットカーです。

## 機能

- **人物追跡**: カメラで登録された人物を検出し、追跡します
- **音声認識**: "Hey, Tom"のウェイクワードで停止し、コマンドを聞き取ります
- **音声合成**: 行動計画の説明や状態を音声で伝えます
- **衝突回避**: カメラ画像から障害物を検出し、衝突を回避します
- **行動計画**: ユーザーの依頼から行動計画を立案・実行します
- **表情表示**: ディスプレイに表情を表示し、動的にコミュニケーションします

## セットアップ

### 1. 依存パッケージのインストール

```bash
cd robot-car-software
pip install -r requirements.txt
```

### 2. pigpioデーモンの起動

Raspberry Pi上でpigpioデーモンを起動します：

```bash
sudo pigpiod
```

### 3. ハードウェアの接続

`robot-car-chassis/parts-Information.md` を参照して、以下を接続してください：

- DCモーター×4とL298Nモータードライバー
- Webカメラ
- マイク
- スピーカー
- ディスプレイ
- バッテリー

## 実行

```bash
cd robot-car-software
python main.py
```

## 使用方法

1. **起動**: ロボットが起動すると、人物追跡モードで動作を開始します
2. **人物登録**: 初回起動時に登録したい人物の画像を撮影して登録します（実装予定）
3. **追跡**: ロボットは登録された人物を追跡します
4. **停止**: "Hey, Tom"と発話するとロボットが停止します
5. **コマンド入力**: タスク（例: "リモコンを探して"）を依頼します
6. **確認**: ロボットが行動計画を説明するので、"ok"と言って実行を承認します
7. **実行**: ロボットがタスクを実行します

## 動作モード

- **IDLE**: 待機中（ウェイクワード待ち）
- **FOLLOWING**: 人物追跡中
- **LISTENING**: 音声コマンド入力待ち
- **TASK_PLANNING**: タスク計画立案中
- **TASK_EXECUTING**: タスク実行中

## 設計原則

- **ドメイン駆動設計（DDD）**: ユビキタス言語を使用
- **レイヤードアーキテクチャ**: ドメイン層、インフラ層、アプリケーション層に分離
- **制約**: すべての移動は`Motor.move()`を使用

## トラブルシューティング

### カメラが開けない
- カメラが正しく接続されているか確認してください
- 他のプロセスがカメラを使用していないか確認してください

### 音声認識が動作しない
- マイクが正しく接続されているか確認してください
- インターネット接続を確認してください（Google Speech APIを使用）

### モーターが動作しない
- pigpioデーモンが起動しているか確認してください: `sudo pigpiod`
- GPIO配線が正しいか確認してください（`infrastructure/motor/pimygpio.py`参照）
